# DevConnect

DevConnect is a full-stack software development Q&A forum where users can register, log in, ask programming questions, and post answers.

## Features

- User registration and login
- Password hashing with bcrypt
- Programming categories
- Create and view questions
- Post and view answers
- MongoDB database storage
- Responsive forum-style dashboard
- REST API built with Express

## Technologies

### Backend

- Node.js

## Installation

1. Clone the repository.
2. Run `npm install` inside the `client` folder.
3. Run `npm install` inside the `server` folder.
4. Create a `.env` file in the `server` folder.
5. Add your MongoDB connection string as `MONGO_URI`.
6. Start the backend with `node server.js`.
7. Start the React frontend with `npm start` inside the `client` folder.
